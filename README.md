# sukima-labs.github.io

Portada de la organización [sukima-labs](https://github.com/sukima-labs): <https://sukima-labs.github.io/>.

HTML estático a mano, sin generador. Cada proyecto con GitHub Pages cuelga de aquí (`/finde/` lo sirve el repo `finde`), así que la propiedad de Google Search Console de la raíz los cubre a todos.

- **No quitar** la etiqueta `google-site-verification` de `index.html`: es la verificación de Search Console.
- Proyecto nuevo publicado → tarjeta en `index.html` y línea en `sitemap.xml`.
